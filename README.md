# Xross Stars 対戦ログメーカー

対戦動画をブラウザで確認しながら、ターン移行、カード使用、攻撃元・攻撃先、ダメージ、覚醒、ラウンド結果を記録して編集用CSVを作るツールです。

## 使い方

1. 公開ページを開く
2. 「動画を開く」から対戦動画を選択する
3. 必要に応じて左右のプレイヤー名・デッキ名を入力する
4. リーダー編成を設定して対戦開始を記録する
5. カード使用やHP処理を記録する
6. 「編集用CSVを保存」でCSVを出力する

作業中の内容はブラウザのローカルストレージへ自動保存されます。CSVを読み込んで作業を再開することもできます。

## 対応動画

推奨形式はMP4コンテナ、H.264 / AVC映像（8-bit・`yuv420p`）、AAC音声です。WebMやHEVCなども利用中ブラウザがデコードできる場合はそのまま読み込みます。MP4 / MOVは選択直後に映像コーデックを確認し、非対応の場合は黒画面になる前にコーデック名・理由・FFmpeg変換コマンドを表示します。

Round 1の先攻はリーダー編成時に左右から選択します。Round 2以降は前Roundの敗者が自動的に先攻になります。記録一覧の時刻欄は直接修正でき、Enterキーで確定します。

記録一覧の鉛筆ボタンから、各イベントの内容をあとから編集できます。アタックの攻撃元・ダメージ先・ダメージ量、派生処理の対象・ダメージ／回復量などを修正すると、そのイベント直前のHPを基準に以後のHP・ダウン判定を時系列で再計算します。動画操作欄の「1.5×」では通常速度と1.5倍速を切り替えられます。

装備タクティクスの能力値を時系列で保持します。ライトシールド、ボディアーマー、サイバネアーマー、メリケンサックと、ラウンド中のパワーフィールドはHP／ATK表示へ反映されます。装備は次Roundへ持ち越し、ラウンド中効果だけRound終了時に解除します。

HPに関係する【アタック後】効果が複数ある場合は、発生元カードを画像付きで一覧表示します。処理するカードを好きな順に選び、「この効果を使う」または「使用しない」を選択できます。記録した派生HP処理には発生元カードのID・画像・効果文も保存されます。

プレイヤー名とデッキ名は任意入力です。空欄のままでも記録・CSV出力でき、入力した場合は対戦開始行の `left_player_name`、`left_deck_name`、`right_player_name`、`right_deck_name` に保存されます。試合開始を記録した後でも編集でき、変更内容は対戦開始行へ自動反映されます。

## プライバシー

選択した動画はブラウザ内でのみ再生され、GitHubや外部サーバーへアップロードされません。ログも明示的にCSVを保存しない限り、利用中のブラウザ内だけに保存されます。
